# 基礎演習テキスト

基礎演習・データサイエンス入門で使うテキストの一覧です。  
テキストは番号順に読み進めてください。教材データは [`../data/`](../data/) にあります。

## カリキュラムの流れ

| 段階 | テキスト | 学ぶこと | 進め方 |
| --- | --- | --- | --- |
| 導入 | [`introduction.md`](./introduction.md) | 研究でプログラミングを学ぶ意義 | 読むだけ |
| 導入 | [`example.md`](./example.md) | 研究データ解析パイプラインの全体像 | 読むだけ |
| Python入門 | [`part_1.md`](./part_1.md) | 変数・リスト・辞書 | Colab のコードセルで実行 |
| Python入門 | [`part_2.md`](./part_2.md) | 条件分岐（`if`）・繰り返し（`for`）・関数（`def`） | Colab のコードセルで実行 |
| データ処理・可視化 | [`part_3.md`](./part_3.md) | `pandas` で CSV を読み、`matplotlib` で散布図を描く | Colab のコードセルで実行 |
| CLI | [`part_4.md`](./part_4.md) | ターミナルでフォルダを作り、データごとに解析して画像を保存する | Colab のターミナルでコマンド実行 |
| 結果の記録 | [`part_5.md`](./part_5.md) | 設定ファイルにまとめ、結果を記録して点検する | Colab のターミナルでコマンド実行 |

大まかには、次の 4 つの流れで進みます。

1. **導入**（`introduction.md`・`example.md`）で、プログラミングを学ぶ目的と研究での使い方をつかむ。
2. **Python入門**（Part 1・2）で、データを扱う基本の文法を覚える。
3. **データ処理・可視化**（Part 3）で、CSV を読み込み、グラフにする。
4. **CLI・結果の記録**（Part 4・5）で、複数のデータを、フォルダと記録ファイルを使って管理する。

Part 1〜3 は Colab のコードセル、Part 4〜5 は Colab のターミナルを使います。  
目安は次のとおりです。Python入門は 1〜2 週間、データ処理・可視化入門は 1〜2 週間、CLI 入門は 1 週間、結果の記録は 1 週間です。

## 各テキストの内容

### 導入

- **[`introduction.md`](./introduction.md)**  
  「プログラミング」と「コーディング」の違いを整理し、研究者の役割、手作業による集計のリスク、AI を使うときに人間が担う検証について説明します。本講座の到達目標もここに書いてあります。
- **[`example.md`](./example.md)**  
  実際の研究リポジトリにある解析パイプラインを、教材用に簡略化して示したものです。現場の記録から、前処理、解析、成果物（要旨・論文）までの流れを確認します。コードの細部ではなく、全体の構造を理解することが目的です。

### Python入門

- **[`part_1.md`](./part_1.md)**: 変数・リスト・辞書  
  数値に名前を付けること、複数の回答をリストにまとめて集計すること、辞書で項目名と値を対応させることを学びます。最後に、表形式のアンケートを辞書とリストで扱う総合演習があります。
- **[`part_2.md`](./part_2.md)**: 条件分岐・繰り返し・関数  
  `if` で値に応じて処理を分け、`for` で複数の回答を順に処理し、`def` で判定や集計を関数にまとめます。Part 1 のアンケートデータを使って、満足度を判定する総合演習を行います。

### データ処理・可視化

- **[`part_3.md`](./part_3.md)**: pandas・matplotlib  
  `pandas` の DataFrame で表を扱い、`pd.read_csv()` で CSV を読み込み、列の取り出し・絞り込み・並べ替えを行います。`matplotlib` の散布図で 2 つの数値の関係を確認し、読み込みから可視化までを一連の手順として実行します。使うデータは [`survey_responses.csv`](../data/survey_responses.csv) です。

### CLI

- **[`part_4.md`](./part_4.md)**: CLI・フォルダ構成  
  Colab のターミナルで `pwd`・`ls`・`cd`・`mkdir`・`cp` を使い、解析用のフォルダを作ります。1 本のスクリプトを作って実行し、それを複製して 4 つのデータ（アンケート、店舗の売上、漁獲、学習時間と得点）に対応させ、散布図を PNG として保存します。末尾には、Linux シェルコマンドの発展課題（paiza）があります。

### 結果の記録

- **[`part_5.md`](./part_5.md)**: 結果の記録  
  基準の値とデータのパスを `src/config.json` にまとめ、スクリプトを設定ファイルから動かします。すべての結果を `outputs/runs.csv` に 1 行ずつ記録し、出力の数を `find` と `wc -l` で点検します。最後に、データの仕様（`docs/specification.md`）と、次に調べること（`docs/issues.md`）を文章として書きます。
